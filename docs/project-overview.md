# Project Overview

## 1. Project Description

This is an independent portfolio project designed to demonstrate practical knowledge of Digital Operations, process management, and Agile methodologies using Jira and Confluence.

The project uses a fictional educational institution and simulated business scenarios focused on improving the student onboarding process.

## 2. Project Objectives

- Practice project and workflow management using Jira.
- Apply Kanban and Scrum methodologies in separate workstreams.
- Map processes and identify improvement opportunities.
- Create operational documentation and standard procedures.
- Organize tasks, priorities, and sprint activities.
- Define performance indicators and measurement criteria.

## 3. Project Structure

The project is divided into two independent workstreams.

### Workstream 1 — Kanban: Digital Operations

Focuses on process mapping, workflow organization, operational documentation, and continuous improvement.

Activities include:
- Mapping the student onboarding process.
- Identifying bottlenecks and improvement opportunities.
- Designing a proposed workflow.
- Documenting the Standard Operating Procedure (SOP).
- Defining performance indicators.
- Organizing tasks through a Kanban board.

### Workstream 2 — Scrum: Student Onboarding Improvement

Focuses on applying Scrum practices to a simulated improvement initiative.

Activities include:
- Creating and prioritizing a Product Backlog.
- Defining a Sprint Goal.
- Selecting items for Sprint 1.
- Writing user stories and acceptance criteria.
- Tracking sprint execution through a Scrum board.

Sprint Review and Retrospective activities are documented as planned until they are actually performed.

## 4. Tools and Methodologies

**Tools**
- Jira — task, backlog, and workflow management.
- Confluence — process and operational documentation.
- GitHub — project versioning and portfolio presentation.

**Methodologies**
- Kanban
- Scrum
- Process Mapping
- Standard Operating Procedures (SOP)
- Performance Indicators (KPIs)

## 5. Project Scope and Limitations

This project is an independent learning and portfolio initiative. All organizations, scenarios, processes, and data are fictional or simulated.

It does not represent an implementation for a real company, a professional client engagement, or measured business results.

The purpose is to demonstrate practical familiarity with the tools, methods, and documentation practices used in Digital Operations and Agile project management.
